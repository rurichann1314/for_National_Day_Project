## 评判标准

### 必要

至少可以 roll D6 任意次

可以实现 roll D4，D6，D8，D12任意切换

可以实现 n D6

可以实现 n D m

可以实现 $n_1$ D $m_1$ ，$n_2$ D $m_2$ ...... 任意组合，最后点数取和

### 额外

支持 Android 平台的编译与安装

支持浏览器 WASM 编译

在 GitHub Pages 上部署 WASM 编译包

在 GitHub Action 上完成三大 JVM 平台安装包编译并 release
